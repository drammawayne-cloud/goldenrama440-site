# Golden Rama 440

Official artist website: https://goldenrama440.com

Edit published content at https://console.richrowmusic.com/addons/admin?site=goldenrama440. Keep the page address `goldenrama440`. Add headings Music, Videos, Photos, About, Booking, and Connect, and publish the page in the Control Center. Public media belongs in its Media Library. GitHub Pages hosts this static site from the `main` branch root; credentials remain in the private console.

AdSense is prepared through `adsense-config.js`; add an approved `ca-pub-` publisher ID after Google approval. The cart and movable chat connect to the shared Rich Row Control Center.
